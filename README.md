# Tableau-Corvid19-Analysis
Use Tableau to create exploratory and actionable dashboards 

The dataset consisted of daily worldwide data of corvid 19 cases during the period
from January 2020 to June 2020 which are aggregated at country and state level.
The data included are Continent Name, Country Region, Date, Positive, Province State,
Country Code, Active, Daily Positive, Daily Total, Death, Hospitalized, Hospitalized
Curr, Recovered, Total Tested.
There were values which consisted of zeroes which was assumed to mean that there
were no new cases on the respective day.
Additionally cumulative daily cases shows to have inconsistencies with total cases
which could be due issues with recording the data by country, but they were
preserved to maintain continuity.

DESIGN REFLECTION

The action dashboard was mainly created to prioritize clarity using key metrics in the
form of KPI cards and threshold indicators.
Whereas the exploratory dashboard was used to help understand trends more
deeply with interactivity.
A consistent palette was used by using orange and red to show risk and blue for
neutral and green hues for recoveries.
Several filters for country, region and dates.to increase interactivity.
